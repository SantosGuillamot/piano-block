# Phase 6 — PR Review follow-up: add `@wordpress/scripts` build + `wp-env`

Review-driven change folded into PR #3 (branch `worktree-1-piano-block-scaffold`). Adopts the two things the original scaffold deliberately deferred — the JS build pipeline and a local WordPress environment — while keeping the block itself a placeholder (no real piano functionality yet).

## Owner decisions (Q&A)

1. **Linting:** keep **Biome** as the linter/formatter; use `@wordpress/scripts` for `build`/`start` only. Do not adopt its ESLint/Prettier/stylelint. Scope Biome away from `build/`.
2. **Layout:** full **`src/` → `build/`** migration with **JSX**; `register_block_type` points at `build/`.
3. **Styles:** adopt **SCSS** (compiled by the build). Biome does not lint SCSS — accepted now that a build exists.
4. **wp-env:** **latest WordPress + PHP 8.x**; use it to run the 5-point smoke test live.

## Working assumptions

- Block stays a **placeholder** (tooling/build/env only).
- **WP 6.3 / PHP 7.4 floors stay** (not adding the Interactivity API, so no 6.5 bump).
- **`build/` is gitignored**; the dev/install workflow is `npm install && npm run build` (documented in README).
- Dev env here is Node 20 (below the declared `>=24`); build/env verified on it, declared floor unchanged.

## Target structure

```
piano-block.php          register_block_type( __DIR__ . '/build' )
package.json             + @wordpress/scripts, @wordpress/env; scripts build/start/env; Biome kept
.wp-env.json             latest core, phpVersion 8.x, plugins ["."]
.gitignore               + /build
biome.json               ignore build/ (+ confirm JSX lints clean)
src/
  block.json             editorScript file:./index.js, style file:./style-index.css, render file:./render.php
  index.js               entry: registerBlockType( metadata.name, { edit } ) + import './style.scss'
  edit.js                JSX edit component (useBlockProps placeholder)
  style.scss             placeholder styles (was style.css)
  render.php             unchanged server render
build/                   generated by `npm run build` (gitignored)
```

Removed from root: `index.js`, `index.asset.php` (build regenerates the asset file), `style.css`, `block.json`, `render.php` (the latter two move into `src/`).

## Steps

1. Install `@wordpress/scripts` + `@wordpress/env` (devDependencies).
2. Create `src/` (block.json, index.js, edit.js, style.scss, render.php); remove old root files; point `piano-block.php` at `build/`.
3. Add npm scripts (`build`, `start`, `env`); add `.wp-env.json`; gitignore `build/`; scope Biome away from `build/`.
4. `npm run build` → verify `build/` output; reconcile `block.json` asset refs with actual output names.
5. `npm run lint` (Biome) clean on `src/`.
6. `wp-env start` → run the 5-point smoke test live (activation / inserter / editor placeholder / save / front-end render).
7. Update README (build + wp-env workflow).
8. Commit logically to the branch, push, update PR #3. Record results in `6 - PR Review/verification.md`.
