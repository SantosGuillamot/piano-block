# Support arpeggios with direction

> Source: [SantosGuillamot/piano-block#28](https://github.com/SantosGuillamot/piano-block/issues/28).
> This file is self-contained; agents do not need to open the source issue.

## Goal

Chords in the piano block can be marked as arpeggiated, including the direction of the arpeggio (e.g. upward or downward), and this is reflected when the music is rendered.
