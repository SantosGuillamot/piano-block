# Add a frontend toggle to show note names

> Source: [piano-block#19](https://github.com/SantosGuillamot/piano-block/issues/19).
> This file is self-contained; agents do not need to open the source issue.

## Goal

On the frontend, a viewer can toggle the display of note names on the piano block on and off.

## Constraints

- The frontend interactivity must be built with the WordPress Interactivity API.
