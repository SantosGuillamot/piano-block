# Design Doc Review

## Verdict: approved

## Reviewer

Owner (assisted workflow)

## Notes

Approved after resolving one open question (note-name input vs AC9). Decision: per-song note-name system, with AC9 read as "one note-name language per song" (Spanish→Spanish, English→English); a song that mixes systems within itself is normalized to the per-song spelling when edited (accepted). Future note-name languages (e.g. German) are out of scope for this feature but accommodated by the approach. All seven key design decisions were chosen by the owner during the assisted Q&A.
